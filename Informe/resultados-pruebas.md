## 1. Objetivo

Documentar los resultados obtenidos durante la ejecución de los casos de prueba de la plataforma de gestión académica, verificando el funcionamiento de sus principales módulos y la integración de sus componentes.

## 2. Entorno de pruebas

Las pruebas se realizaron considerando el siguiente entorno tecnológico:

- Frontend: Angular y TypeScript.
- Backend: Python y FastAPI.
- Base de datos: PostgreSQL mediante Supabase.
- Machine Learning: Python y scikit-learn.
- Infraestructura: Docker Compose.
- Navegador: Google Chrome u otro navegador compatible.
- Datos: registros académicos sintéticos.

## 4. Observaciones

Durante la ejecución de las pruebas se registrarán:

- Errores encontrados en las funcionalidades.
- Problemas de comunicación entre frontend y backend.
- Dificultades en el registro y almacenamiento de calificaciones.
- Problemas en la visualización de resultados de Machine Learning.
- Detalles de adaptación de las interfaces en dispositivos móviles.

## 5. Evidencias

Se recopilarán capturas de pantalla que permitan demostrar la ejecución de las pruebas y el funcionamiento de los módulos.

Las evidencias se organizarán de acuerdo con la funcionalidad evaluada y su código de prueba.

## 6. Conclusión

La ejecución de las pruebas permitirá identificar el nivel de funcionamiento de la plataforma, verificar la integración de sus componentes y detectar posibles errores antes de la presentación del proyecto APF3.

Los resultados definitivos se incorporarán después de ejecutar y verificar cada caso de prueba.
